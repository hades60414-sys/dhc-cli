# 例行工作（DHC CLI「例行」分頁）

這個資料夾底下每個子資料夾是一項例行工作（例：`月報`），每月、每季重複產出同一份報告。使用者通常只說一句「更新10月」「做 Q3」。

側欄「例行」分頁按「新增例行工作」就會在這裡建資料夾並註冊成專案。

## 每項例行工作的資料夾

```
<項目>\
  CLAUDE.md      這項的規格：產出什麼、資料從哪來、怎麼算、檔名規則、交給誰、注意事項
  範本\          上一期或公版檔案
  產出\<期別>\   每期一個資料夾，例：產出\2026-10\
  執行紀錄.md    每期一行：日期、期別、用了哪些資料（含資料截止時間）、檢核結果、有沒有對不上的地方
```

## 使用者說「更新 X 月／X 季」時

1. 讀本項 `CLAUDE.md`、`執行紀錄.md` 最後幾行，找到最近一期的 `產出\` 當參考。
2. 依規格抓當期資料。拿不到的資料列清楚請使用者提供，不要用舊資料或猜的數字補。
3. 產出放 `產出\<期別>\`，檔名照規格；同期已有檔案時先問要不要覆蓋。
4. 數字要用程式驗算，並和上一期比對：變動異常大的項目列出來給使用者看。對不上就說對不上、附證據，不硬湊。
5. 在 `執行紀錄.md` 追加一行。過程中使用者糾正了做法，就順手改本項 `CLAUDE.md`，下次照新的做。

## 這項還沒有 CLAUDE.md（新項目）

先請使用者提供上一期的成品和做法說明（或來源資料位置），讀完後寫出本項 `CLAUDE.md` 規格草稿、建好 `範本\`、`產出\`、`執行紀錄.md`，給使用者確認後再做第一期。

## 規則

- 報告裡引用的外部數據、日期要標來源與資料截止時間。
- 本機腳本優先用 Node.js。
