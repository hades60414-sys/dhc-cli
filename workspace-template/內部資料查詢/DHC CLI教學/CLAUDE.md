# DHC CLI 教學專區（給 AI Agent 讀）

使用者在這個專區問「DHC CLI 怎麼用」。用白話、短句回答，先給做法再補說明；這份文件沒寫到的就說沒寫到，請使用者看畫面上的提示或 README，不要編。

## 工作區是什麼

所有專案放在工作區根目錄（預設是家目錄下的 `DHC Workspace`，可在 repo 的 `dhc.config.json` 改 `workspaceRoot`）。根目錄底下：

| 資料夾 | 用途 |
|---|---|
| `<專案名>\` | 一般專案，一件工作一個資料夾，側欄「專案」分頁會列出來 |
| `例行工作\<項目>\` | 每月／每季重複的報告，列在「例行」分頁 |
| `內部資料查詢\<專區>\` | 問答專區，列在「查詢」分頁（就是你現在這裡） |
| `蒸餾任務\` | 蒸餾模式的紀錄（按輸入框的燒杯後才會用到） |

每個資料夾裡的 `CLAUDE.md` 是給 AI 的說明：寫這個專案要做什麼、資料在哪、有什麼規矩。AI 開新對話時會先讀它。

## 側欄分頁

- **專案**：工作區根目錄底下第一層的資料夾。點專案展開對話，按「新增工作階段」開新對話。用「新增專案」建新資料夾。
- **例行**：每月／每季重複的報告。按「新增例行工作」輸入名稱（例：月報），會建好資料夾並註冊。第一次點進去，AI 會先請你給上一期成品和做法，寫好規格；之後只要說「更新10月」就照上次的做法產新的。共用規則在 `例行工作\CLAUDE.md`。
- **查詢**：問答專區。預設只有這個教學專區；要接你自己的文件或資料庫，見 repo 的 `docs/build-your-own-rag.md`，做好後在 `內部資料查詢\` 底下建一個資料夾、寫 `CLAUDE.md`，再到側欄註冊成專案。
- **執行中**：正在跑的對話（包含 AI 自己開的子代理），可以從這裡跳回去看進度。

側欄上方的搜尋框可以搜專案名，也可以搜對話內容。

## 對話與輸入框

- **Enter** 送出、**Shift+Enter** 換行（設定裡可改成 Ctrl+Enter 送出）。
- 輸入框是空的時按 **↑／↓** 可以叫回之前送過的訊息。
- 在畫面空白處按 **Enter** 會跳回輸入框。
- **Ctrl+K**（Mac：⌘K）開指令面板，可以快速找專案、對話和動作。
- 可以貼上或拖曳圖片、檔案當附件；圖片可以先用畫筆、方框、文字標註再送出（標註時 **Ctrl+Z** 復原）。
- **⚡ 快閃任務**：一次性的對話，結束後進回收桶，到期自動刪除。
- **燒杯（蒸餾模式）**：做這件工作時，你的糾正與選擇會被記下來；說「結案」就整理成知識檔和技能草稿。
- **月亮（夜間排程）**：把訊息排到晚上依序執行，適合等額度重置後再跑的長任務。

## 其他

- **待辦**：右側邊緣的把手打開「今日待辦」；「全部待辦」用重要／緊急四格整理。
- **工具庫**：文件共編、試算工作台、簡報、白板（系統規劃、SOP 泳道、心智圖、資料流程）等小工具，畫好的白板可以直接叫 AI 開工。
- **用量**：側欄底部顯示 Claude 訂閱的 5 小時與每週用量；拿不到時會寫原因。
- **設定**：左下「設定」。個人／團隊模式、要顯示哪些 AI Agent，改 repo 的 `dhc.config.json` 後重啟伺服器。

## 遇到狀況

- **側欄沒有我的資料夾**：資料夾要在工作區根目錄底下第一層，而且要用「新增專案」註冊過。
- **對話沒有回覆**：看側欄底部的用量與登入提醒；Claude 登入過期就在主機執行 `claude` 重新登入。
- **畫面怪怪的**：先重新整理（F5）；版本更新後也要重新整理才會換新版。
